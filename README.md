# Tsuyoshi Nagamine

Founder of [EFG technologies](https://efg-technologies.com) (Tokyo, Japan), building **[Zeed](https://zeed.run) — the AI browser for Linux**.

- 🌐 Zeed is a Chromium-based AI browser that reasons over your open tabs, memory, and reading context. **Linux-first**, privacy by design, bring-your-own-LLM via OpenRouter.
- 🔎 Also building **[Zeed Search](https://search.zeed.run)** — AI-era search.
- 🐧 Daily driver: Hyprland / Wayland on Arch Linux, Zsh + Starship, Neovim, Ghostty.
